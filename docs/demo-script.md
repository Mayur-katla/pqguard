# PRGuard Live Presentation Script

Target length: 5 minutes.

1. Open the one-page dashboard.
2. Scan a real public GitHub repository and explain that Track A is primary.
3. Show the average Hollow Score, top Human Proof Score, and heatmap from live PR data.
4. Click the highest-risk PR.
5. Walk through Hollow Score, Human Proof Score, missing proof, evidence, changed files, commits, and comments.
6. Open Evidence Map and show which claims are unsupported or partial.
7. Open Fix Plan and copy the recommended reviewer actions.
8. Paste live Docs, Hiring, and Communications text into the analyzer and switch modes.
9. Open CI Gate and generate a threshold workflow.
10. Export a PDF or CSV report.
11. Close with: PRGuard catches content that looks complete but lacks proof a human understood it.
